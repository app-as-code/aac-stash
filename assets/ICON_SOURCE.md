# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/stash.svg` | Default (fallback) |
| `icon-light.svg` | `svg/stash-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/stash-light.svg` | Light-colored logo for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/stash.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/stash-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/stash-light.svg
